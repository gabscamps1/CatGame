# O que é Nekopan Mix!?
Nekoapan Mix! é um jogo de puzzle multiplayer free-for-all onde os jogadores competem entre si para serem o melhor gato padeiro do mundo! 
Para isso, os jogadores devem acumular doces em seus respectivos potes e combinar doces iguais, que se fundem em um doce maior. Quanto maior o doce, mais pontos o jogador ganha, quem tiver uma quantidade maior de pontos: ganha o jogo, mas tome cuidado pois se você encher o seu pote até seu limite, 
você perderá uma vida e terá que jogar seus doces no lixo e recomeçar, se você encher o pote duas vezes: você é eliminado. 
No entanto, administrar uma padaria nem sempre é uma tarefa fácil: eventos inesperados, como um apagão ou um sucesso de vendas, podem surgir e tanto ajudar quanto atrapalhar o seu progresso.

# Qual o nosso objetivo com Nekopan Mix!?
Nosso bjetivo é criar um jogo que vire um fenômeno cultural no Brasil assim como sua inspiração, Suika Games, foi um fenômeno cultural do japão, 
assim ajudando a crescer o repertorio de jogos Brasileiros e a nossa cultura em desenvolvimento de jogos.
